## From source


You will first need to download [jamovi](https://www.jamovi.org/download.html). 


You can clone this repository and compile the module within R with 

```
library(jmvtools)

jmvtools::install()

```

# Install in R

The R version of the module does not really do anything more than what can be done in lavaan. Please use lavaan in R

## Regression tests

Run the tests from the repository root against the current source, without
reinstalling the module:

```r
testthat::test_local()
```

To run only the numerical regression checks:

```r
testthat::test_local(filter = "numerical-regression")
```

These tests compare SEMLj's result tables with independent `lavaan` fits and
ordinary least squares, and retain fixed CFA benchmarks to detect changes even
when both SEMLj and lavaan change. They cover regression coefficients and R²,
CFA loadings and fit indices, endogenous latent paths through both R entry
points, equal multigroup loadings, FIML missing-data handling, defined effects,
and robust standard errors and scaled tests. Estimates, standard errors,
confidence intervals, and standardized estimates are compared with a numerical
tolerance of `1e-5` to allow small platform and optimizer differences.

The GUI R entry-point test supplies the model syntax normally generated by the
JavaScript interface; these R tests do not exercise the jamovi widgets themselves.
When a benchmark fails, investigate the model, options, and dependency versions
before changing its expected values. The suite also runs during `R CMD check`.
